Custom Post Types Created by Plugin:
=====================================

After activating the plugin, these new content types will be available:

1. Artists           (Post Type: artist)
   - Menu icon: 👥 (admin-users)
   - Archive: /artist/
   - Single: /artist/artist-name/

2. Exhibitions       (Post Type: exhibition)
   - Menu icon: 🖼️ (images-alt2)
   - Archive: /exhibition/
   - Single: /exhibition/exhibition-name/

3. Events            (Post Type: event)
   - Menu icon: 📅 (calendar)
   - Archive: /event/
   - Single: /event/event-name/

4. Artworks          (Post Type: artwork)
   - Menu icon: 🎨 (art)
   - Archive: /artwork/
   - Single: /artwork/artwork-name/


Custom Taxonomies:
==================

1. Art Medium        (Taxonomy: art_medium)
   - Applied to: Artworks
   - Type: Hierarchical (like categories)
   - Examples: Painting, Sculpture, Digital Art, Photography

2. Exhibition Year   (Taxonomy: exhibition_year)
   - Applied to: Exhibitions, Events, Artists, Artworks
   - Type: Hierarchical
   - Examples: 2024, 2025, 2026

Development Workflow:
====================

1. Install WordPress in htdocs folder
2. Copy theme and plugin from this repo
3. Activate theme and plugin in WordPress admin
4. Start adding content
5. Customize theme files as needed
6. Commit changes back to this repository

Only commit:
✓ wp-content/themes/christiania-biennale/
✓ wp-content/plugins/christiania-biennale-functionality/
✓ Documentation files
✓ docker-compose.yml
✓ .gitignore

Never commit:
✗ Core WordPress files
✗ wp-config.php
✗ wp-content/uploads/
✗ Other themes/plugins
